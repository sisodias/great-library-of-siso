Law firms

Begin with supervised intake, approved-template assembly and evidence-preserving document review. Compare against the firm's existing software before replacing it. Neither exposure estimates nor a repository's features establish cash savings.

All industriesCode valuationFoundryProject / agent JSON

Research dated 2026-09-05. Business value remains unmeasured. Software descriptions are documented capabilities; each project must verify fit, rights and outcomes before adoption.

United States research pilot; state/practice-area requirements still need an authorized firm-specific review.

What the evidence supports

An occupational task inventory identifies legal-assistant document preparation, records organization and research. A preregistered 2024 study found errors in the legal AI research tools it tested despite retrieval grounding. This supports decomposing tasks and measuring supervised assistance; it does not supply a law-firm-wide automation rate or a current vendor-performance ranking.

Processes to test

Client intake and missing-information chase

Collect and normalize supplied fields; flag missing facts and possible matches; never accept a conflict or engagement automatically.

Measure
Human minutes per complete, accepted intake including review and chase
Reject the idea if
Reject if a known conflict/identity ambiguity is suppressed or completed intake takes no less total human time.
Human authority
Firm-designated intake reviewer; lawyer owns conflict/engagement decision.

[mycase] [actionstep] [docassemble]

Approved-template document assembly

Populate approved templates from validated interview answers and return a draft plus field provenance.

Measure
Human minutes per correct, reviewed document; critical field errors
Reject the idea if
Reject if version/party/amount/date errors survive review or review effort erases assembly savings.
Human authority
Qualified professional approves template/rules and final legal document.

[onet] [docassemble] [mycase]

Document extraction and source-linked review

Extract candidate facts with document/version/page references; reviewers accept/reject each finding.

Measure
Correct accepted findings per reviewer hour, with unsupported findings counted
Reject the idea if
Reject if a finding lacks its supporting source or cross-matter retrieval exposes restricted material.
Human authority
Matter owner controls access and interpretation; extracted text is not legal advice.

Approved-document signing coordination

Prepare a signing envelope only from approved immutable content; require explicit release authority.

Measure
Human coordination minutes per correctly completed signing workflow
Reject the idea if
Reject if signer/document identity changes undetected or benefit depends on bypassing approval.
Human authority
Authorized firm sign-off; no automatic filing or signing.

[mycase] [repo-documenso]

Client updates and administrative follow-up

Draft status updates from current records; route for review and send only when authorized.

Measure
Net human minutes per accurate approved update, including exception/retry review
Reject the idea if
Reject if stale status is sent as current, recipients cross matter boundaries or retries duplicate an action.
Human authority
Firm communication owner retains recipient/content/send control.

[mycase] [actionstep] [repo-activepieces]

Time/billing exception review

Surface missing time descriptions, inconsistent identifiers or rejected line items in a read model; keep financial authority upstream.

Measure
Review minutes per resolved exception; correction rate; actually recovered contribution margin
Reject the idea if
Reject if trust/billing state is overwritten or saved billable hours are counted both as cash and new revenue.
Human authority
Billing/accounting owner; no trust-ledger or invoice replacement authorized.

Business value and a falsifiable pilot

No firm baseline, invoices, achieved automation rate, review/rework time, operating cost, displacement proof or eligible-population measurement. Null is not zero.

Within one authorized firm, compare matched routine work under the incumbent workflow and supervised candidate workflow. Start with synthetic/redacted fixtures; pre-register which documents/actions are in scope before using live data.

  • Human time including review/rework is not lower than the matched baseline.
  • Any privileged record crosses an unauthorized boundary or an unapproved external action occurs.
  • The result depends on treating draft/closed status as accepted legal work.
  • Measured first-year net cash is not positive for a cash-savings offer; capacity gains alone are not cash.
Read the shared value model

Limits

  • This is not legal advice, product admission or an industry-wide value forecast.
  • Current software adoption prevalence and current subscription prices were not verified; named offerings are not assumed to be installed.
  • No claim that a generic repository replaces the whole legal practice stack.
  • Rights, security, accessible UI, restoration and integration behavior remain product-owner gates.
