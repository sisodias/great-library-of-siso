Receipts, not vibes

Agent Brain’s verifier creates isolated databases, applies three immutable migrations twice, races two workers for one step, versions artifacts, replays offline writes, and runs dry-run/apply/idempotent imports for both reviewed legacy layouts. Private path artifacts never copy; memory and timeline require explicit opt-in. Skills Hub proves its adapters route stable Brain commands, its telemetry writes only to a Skills-owned store, and Task Commander contains no raw SQL or topology snapshot.
