SISO Agents workspace layout

The machine-neutral local home for reusable agent Works is $SISO_WORKSPACE/SISO_Agents. It is a flat checkout grouping, not a monorepo, package, or identity authority.

Why flat?

Each Work remains independently cloneable, forkable, releasable, and replaceable. Dependencies and compositions are recorded as typed registry relationships; directory nesting would falsely imply ownership and would become stale as the stack evolves.

What changed on 30 July 2026

Eight clean independent agent checkouts were promoted from temporary or nested local locations into the flat Agents domain. The temporary SISO_Library_Repos holding folder was retired after its two Research Works were filed under Knowledge. No compatibility symlink was introduced. The Agent Base path stayed stable because the frozen Agency domain contained 185 references at inspection time.

Identity remains portable

Local placement never changes a Great Library Work ID, Release Manifest, Snapshot, source locator, or public URL. A contributor may clone one Work, the whole selected Snapshot, or any Assembly without reproducing this laptop layout.
