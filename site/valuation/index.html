What reusable code is worth

A falsifiable value model and ten repository examples, with the missing measurements kept visible.

All industriesCode valuationFoundryProject / agent JSON

Research dated 2026-09-05. Business value remains unmeasured. Software descriptions are documented capabilities; each project must verify fit, rights and outcomes before adoption.

The model

Any unknown mandatory input produces null, not zero, a planning default or an invented range. A zero is permitted only as an explicit measured value with a receipt. Numeric synthetic fixtures test the formula only and are never market estimates.

annual capacity hours
annual_units * (baseline_human_minutes_per_unit - assisted_human_minutes_per_unit) / 60; assisted time includes review, rework and exception handling
first year net cash
verified_cancelled_software_spend + verified_realized_labor_cash_savings + verified_incremental_contribution_margin + verified_risk_loss_reduction - annual_operating_cost - first_year_change_cost
capacity shadow value
annual_capacity_hours * measured_loaded_hourly_cost; report as non-cash capacity equivalent, never add to first_year_net_cash without observed monetization
societal resource value
eligible_businesses * observed_adoption_fraction * measured_net_real_resource_benefit_per_business - measured_transition_externalities; not aggregate software revenue, willingness to pay, firm count × repo stars, or gross billable hours
evidence score
count of verified items among seven named receipt gates; display numerator/denominator. This is evidence completeness, NOT a valuation or quality multiplier.

When to reject a value claim

  • Net human time including review/rework is not lower than baseline: reject the productivity claim.
  • Actual cancellable spend is zero or contract cannot be terminated: reject the displacement term.
  • The same benefit ID is allocated in full to multiple modules: reject the aggregate.
  • An observed first-year net cash result is non-positive: reject a cash-saving offer unless a different explicitly authorized goal is documented.
  • Critical data/authority error occurs or baseline quality is not preserved: no adoption regardless of monetary result.
  • An outcome falls outside a preregistered predicted interval: forecast calibration fails and requires revision.
