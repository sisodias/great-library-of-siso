SISO Agent Stack keeps the working stack together. Component roles describe responsibility inside this assembly; they are not global categories.

Assembly / 1.0.0

One stack.
Four required components.

A human can state an outcome, agents can execute it through persistent coordinated lanes, and a future agent can recover the verified project state without reconstructing chat.
