UNFUCK — whole-project ownership prompt

A reusable prompt that gives one frontier agent accountable ownership of a whole project, paired with a one-page dispatch brief, the ranked God Questions with written falsifiers, eight machine-readable research contracts, and eleven agent skills for search, verification, classification and delegation.
