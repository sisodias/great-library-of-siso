Laptop Estate Canonicalization

The laptop is replaceable infrastructure. The Great Library is the sole identity and lineage registry for accepted Works, Releases, Snapshots, and preservation-aware source intake.

Canonical rule: local folders, worktrees, databases, runtime state, and physical placement do not create Works. Public Works retain stable IDs. Exact local placement lives only in an ignored private overlay attached to those IDs.

Current baseline

This intake is anchored to Whole Library V37, gls:snapshot:29c1b8ef-d173-4a18-b15b-291412d43fc9. Existing public Works are linked by stable IDs; they are not duplicated for each checkout or local location.

One logical answer surface, several databases

The People Graph is one assembled logical graph, not one physical database. Foundry, GitHub identity, ingestion, working, recovery, and assembled graph databases keep independent owners and roles and are attached read-only where needed.

What is deliberately excluded

This public intake contains no credentials, personal records, client source, raw databases, raw transcripts, machine-specific paths, private topology, mutable runtime state, or rights-unclear payloads.

Publication stop conditions: unknown ownership, unclear rights, private or client material, credentials, raw sessions, machine-local locators, destructive movement without authority, or promotion without a coherent owner, Release, and verification surface.
