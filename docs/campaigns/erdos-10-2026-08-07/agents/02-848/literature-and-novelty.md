# Literature and novelty boundary

The goal of this branch is formal correctness, not a priority claim.

A public unrefereed all-N candidate predates this Prompt 2 formalization, so translating or independently certifying that candidate cannot honestly be described as the original discovery of the all-N argument.

The upstream asymptotic theorem is also prior work and is reused only at an exact pinned source revision.

Possible novelty on this branch is limited to the formal verification layer: exact statement repair, bridges, checker semantics, and any newly kernel-verified translations of previously non-formal components. Whether any such formal contribution is publication-novel requires a separate current literature audit.

Do not use `NOVELTY-VERIFIED RESOLUTION` solely because Lean accepts a proof.
